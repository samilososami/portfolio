Menos pantalla.
Más conversación.

Un cliente centrado en una cosa: escribir, preguntar y leer.

CardGPT nace de una idea sencilla: aprovechar el teclado y la pantalla del Cardputer para conversar con modelos de lenguaje sin recurrir al móvil. El firmware se conecta directamente al servicio por Wi-Fi; no necesitas mantener un ordenador como intermediario.

La interfaz adapta la conversación a 240 × 135 píxeles. Muestra las respuestas a medida que llegan, permite desplazarse por el historial de la sesión y utiliza la paleta original del proyecto: verde oscuro casi negro, paneles cálidos y texto claro.

No pretende trasladar toda la aplicación ChatGPT a una pantalla diminuta. La versión actual es solo texto: no tiene voz, micrófono, dictado, adjuntos ni sincronización de conversaciones con la web de ChatGPT.

CardGPT es independiente y experimental. No está afiliado, patrocinado ni respaldado por OpenAI, ChatGPT o M5Stack. El acceso y las cuotas dependen de tu cuenta; los cambios del servicio pueden afectar al funcionamiento.

De encenderlo
a empezar a escribir.

El primer arranque te guía. Los siguientes recuerdan tus ajustes.

  1. Conecta la red.

    Selecciona una Wi-Fi de 2,4 GHz. Si el SSID está oculto, elige «Añadir red wifi» al final de la lista e introduce sus datos manualmente.

  2. Vincula tu cuenta.

    El Cardputer muestra un QR, la dirección de inicio de sesión por dispositivo y un código. Completa el proceso en un navegador; la autorización se detecta automáticamente.

  3. Elige cómo conversar.

    Tras verificar la conexión y consultar el catálogo, puedes escoger modelo y esfuerzo de razonamiento desde Ajustes. Solo se ofrecen las opciones que devuelve el servicio para tu cuenta.

  4. Escribe y envía.

    Pulsa Enter para enviar. Los puntos animados indican que se espera la respuesta, que después aparece de forma progresiva en pantalla.

Los detalles también importan.

LECTURA

Texto legible.

Acentos y signos españoles, una fuente adaptada y un framebuffer para reducir el parpadeo. Los emojis se filtran para evitar cuadros de glifos no disponibles.

AUTONOMÍA

Todo en flash.

Wi-Fi, sesión e idioma se guardan en el dispositivo. Una vez instalado, CardGPT funciona sin microSD. El historial del chat solo vive en RAM.

CONTROL

Sin ruido visual.

El indicador de batería usa una media de muestras y se actualiza cada 30 segundos. El audio está desactivado: la experiencia es deliberadamente silenciosa.

Tus datos.
Dentro del dispositivo.

Las credenciales y los ajustes se guardan en la flash interna y se conservan al apagar o reiniciar. Reinstalar desde el flasher los borra: cada instalación es limpia y tendrás que configurar de nuevo la Wi-Fi y vincular tu cuenta.

Se emplean envolturas AES-256-GCM, pero la clave deriva de datos del dispositivo y un contexto público. No es una protección fuerte frente a acceso físico ni sustituye el cifrado de flash y Secure Boot. No compartas volcados de memoria y revoca el acceso antes de ceder el equipo.

Las conversaciones se envían al servicio de OpenAI por TLS validado y quedan sujetas a sus condiciones. El flasher no solicita ni recibe tus credenciales. Lee el modelo de seguridad del proyecto para conocer sus límites.

Instalarlo,
sin intermediarios.

Un firmware completo

Abre el flasher, conecta el Cardputer ADV por USB y confirma la instalación. No necesitas un launcher, ningún firmware previo ni preparar la memoria. CardGPT incluye todo lo necesario para arrancar directamente.

Primera instalación o reinstalación

El proceso es el mismo: la web comprueba el chip, los 8 MB de flash, las protecciones y el archivo; después de tu confirmación borra la memoria, instala y verifica el resultado. Al arrancar, el asistente te guía para conectar la Wi-Fi y vincular tu cuenta.

Necesitas un navegador Chromium de escritorio con Web Serial, una conexión HTTPS y un cable USB de datos. Desde otros navegadores puedes descargar CardGPT.bin, una imagen completa de 8.388.608 bytes para instalar desde 0x0 con otra herramienta compatible.

Se borran todos los firmwares y datos de la flash interna, incluido cualquier launcher, la sesión, las redes Wi-Fi y los ajustes. Conserva una copia de lo importante y no desconectes el cable durante la instalación.

Lo que conviene saber.

¿Sirve para cualquier Cardputer?

Esta versión está preparada y probada para M5Stack Cardputer ADV con ESP32-S3 y 8 MB de flash. El Cardputer original y otras placas no se consideran compatibles sin adaptar y comprobar el hardware.

¿Qué modelos puedo usar? ¿Necesito pagar una API?

El firmware utiliza el inicio de sesión por dispositivo de Codex, no una API key configurada manualmente. Consulta el catálogo de tu cuenta para ofrecer modelos y razonamiento. Eso no garantiza que cualquier modelo, plan o cuota esté disponible: manda el acceso que permita el servicio.

¿Se conserva el historial al apagarlo?

No. Wi-Fi, sesión y preferencias se guardan en flash; los mensajes permanecen en RAM durante la sesión. El contexto también está limitado por la memoria del dispositivo. Ctrl+L limpia el chat cuando está listo para entrada.

¿Hay voz o dictado?

No. La versión actual es exclusivamente de texto. Se han retirado las integraciones de voz y el audio está desactivado.

¿Puedo modificarlo y compilarlo?

Sí. El repositorio incluye el código, recursos, dependencias fijadas y scripts de preparación y compilación. El código original tiene licencia MIT; las bibliotecas y marcas mantienen sus propias licencias y derechos.

¿Qué hago si deja de iniciar sesión?

Comprueba la red y el acceso de tu cuenta, consulta las releases e issues y evita publicar tokens o contraseñas en tus reportes. La integración no es una API pública estable para este dispositivo y puede requerir cambios si el servicio se modifica.
